# AI Engineering Mastery

A six-month, evidence-driven programme for progressing toward Senior AI Engineer / AI Systems Engineer roles at top technology companies.

## Target profile
**Senior AI Systems Engineer** — specialisation in Applied AI, Distributed Systems and LLM Infrastructure. Build toward Staff / Principal engineering over time; target senior-level opportunities first.

## Five priorities and preparation allocation
| Priority | Track | Allocation |
|---|---|---:|
| 1 | AI Systems Engineering | 30% |
| 2 | Distributed Systems & System Design | 25% |
| 3 | Data Structures & Algorithms | 20% |
| 4 | ML Fundamentals & PyTorch | 15% |
| 5 | Production Infrastructure & MLOps | 10% |

See [the detailed six-month roadmap](curriculum/ROADMAP.md) for the exact topics, sequence and outcomes.

## How to use this repository
- Learn one lesson at a time; reading is not mastery.
- Every major topic requires implementation, testing, trade-off analysis and assessment.
- Use this repository as the durable record, ChatGPT as tutor/reviewer, and your local environment as the lab.
- Record sessions in `modules/`; update `PROGRESS.md` and `NEXT_SESSION.md`.
- Never publish employer code, customer data, credentials, confidential prompts or proprietary architecture.

## Weekly time budget
Target 15 focused hours outside existing work:
- DSA and coding: 5h
- Distributed systems: 3h
- AI systems: 3h
- Project implementation: 3h
- System design / interview preparation: 1h

This schedule is a target, not a reason to sacrifice sleep. Reduce the volume when work or recovery requires it; preserve consistency.

## Definition of done
A topic is complete only when you can explain it from first principles, implement it independently, test failure modes, discuss trade-offs and answer interview questions.
