# AI Engineering Mastery

A six-month, evidence-driven programme for progressing toward Senior AI Engineer / AI Systems Engineer roles, specialising in production AI systems, LLM infrastructure, RAG, agentic systems, evaluation and reliability.

## Target profile
**Senior AI Systems Engineer** — able to design, implement, evaluate and operate production-grade AI systems. Longer-term progression toward Staff / Principal engineering.

## Five priorities and preparation allocation
| Priority | Track | Allocation |
|---|---|---:|
| 1 | AI Systems Engineering | 40% |
| 2 | Distributed Systems & System Design | 25% |
| 3 | Production Infrastructure & MLOps | 15% |
| 4 | Data Structures & Algorithms | 10% |
| 5 | ML Fundamentals & PyTorch | 10% |

See [the revised six-month roadmap](curriculum/ROADMAP.md) for the detailed sequence and outcomes.

## How to use this repository
- Learn one concept at a time; reading is not mastery.
- Use ChatGPT as the primary instructor, reviewer and technical sparring partner.
- Focus on first principles, internal mechanisms, architecture, trade-offs and production failure modes.
- Use code to validate understanding and build systems; keep DSA practice as a targeted supporting track.
- Use this repository as the durable record and your local environment as the engineering lab.
- Record sessions in modules; update PROGRESS.md and NEXT_SESSION.md.
- Never publish employer code, customer data, credentials, confidential prompts or proprietary architecture.

## Weekly time budget
Use the existing 15-hour target as a planning ceiling, not a mandate. Prioritise AI systems, distributed systems and project work. Keep a sustainable DSA/ML maintenance cadence. Reduce volume when work or recovery requires it; do not sacrifice sleep.

## Definition of done
A topic is complete only when you can explain it from first principles, reason about architecture and trade-offs, analyse failure modes, demonstrate implementation or a concrete implementation plan, and defend the design.
