# AI Engineering Mastery

A six-month, evidence-driven programme for progressing toward Senior AI Engineer / AI Systems Engineer roles at top technology companies.

## Five learning tracks
1. AI Systems Engineering — primary specialisation.
2. Distributed Systems & System Design.
3. Data Structures & Algorithms.
4. Machine Learning & PyTorch.
5. Production Infrastructure & MLOps.

## How to use this repository
- Learn one module at a time; reading is not mastery.
- Every major topic requires implementation, testing, trade-off analysis and assessment.
- Use this repository as the durable record, ChatGPT as tutor/reviewer, and your local environment as the lab.
- Record sessions in `modules/`; update `PROGRESS.md` and `NEXT_SESSION.md`.
- Never publish employer code, customer data, credentials, confidential prompts or proprietary architecture.

## Repository map
- `curriculum/` — roadmap, learning method and resources
- `modules/` — technical lesson notes
- `labs/` — runnable experiments
- `assignments/` — independent challenges
- `projects/` — capstone specifications
- `assessments/` — diagnostics and rubrics
- `weekly-reviews/` — retrospectives
- `PROGRESS.md` — master progress record
- `NEXT_SESSION.md` — durable lesson handoff

## Suggested weekly allocation (15 focused hours)
- DSA and coding: 5h
- Distributed systems and system design: 3h
- AI systems: 3h
- Project implementation: 3h
- System design / interview practice: 1h

Adjust to a sustainable schedule. Do not compromise sleep.

## Definition of done
A topic is complete only when you can explain it from first principles, implement it independently, test failure modes, discuss trade-offs and answer interview questions.
