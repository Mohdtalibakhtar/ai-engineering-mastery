# 90-Day Execution Roadmap

The first 90 days turn the five-track curriculum into working engineering evidence. The roadmap is sequenced in three phases; DSA practice continues throughout.

## Days 1–30 — Rebuild fundamentals
**Focus**
- Daily Python and DSA practice.
- Concurrency and async programming.
- Distributed-systems fundamentals.
- Transformer architecture and inference foundations.
- Start the Distributed Agent Runtime.

**Deliverable:** a working runtime skeleton with task queues, persistent state and retry behaviour. Document its architecture and tests.

## Days 31–60 — Develop engineering depth
**Focus**
- Kafka and Redis.
- Database scaling, transactions and isolation.
- LLM inference optimisation.
- RAG and agent evaluation.
- Docker and Kubernetes foundations.
- Continue DSA and system-design practice.

**Deliverable:** benchmark the agent runtime and build an initial LLM inference gateway with routing, rate limits and telemetry.

## Days 61–90 — Production engineering and interviews
**Focus**
- Load testing and performance profiling.
- Observability and failure recovery.
- Improve TraceCheck rather than starting another evaluation project.
- System-design interview practice.
- Coding interview simulations.
- Document authorised engineering achievements from Zavmo and enterprise workflow work.

**Deliverable:** three portfolio-quality engineering case studies, measurable project benchmarks and an interview-readiness assessment.

## Weekly review gates
At the end of each week record:
- Focused hours completed and sustainability.
- DSA patterns covered and problems independently solved.
- One engineering concept explained without notes.
- Code, tests, benchmark or design document produced.
- Biggest gap and next week's three outcomes.

## Guardrails
- Do not publish employer code, customer information, credentials, internal prompts or confidential architecture.
- Do not invent business or performance metrics. Establish baselines and measure changes.
- Prefer a smaller tested implementation over a broad unfinished feature list.
