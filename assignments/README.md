# Assignments

Each assignment should define the problem, constraints, acceptance criteria and reflection. Attempt independently before asking for a complete solution.

1. Implement scaled dot-product attention using plain PyTorch operations.
2. Implement a bounded asynchronous worker pool with cancellation and exception handling.
3. Implement an LRU cache and test eviction semantics.
4. Compare dense-only retrieval with hybrid retrieval on a small labelled dataset.
5. Write a system design for a durable task execution service.
